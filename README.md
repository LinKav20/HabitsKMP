# Habits

Приложение для Android и iOS, которое помогает поддерживать привычки и следить за настроением. Можно спланировать регулярные занятия, отмечать их выполнение и смотреть, как прошла неделя.

## Что можно делать

- Создавать привычки: задавать название, эмодзи, дни недели и срок действия.
- Видеть привычки на выбранный день и отмечать выполненные.
- Оценивать настроение каждый день.
- Просматривать недельную историю привычек и график настроения.

Данные хранятся на устройстве. Для начала работы регистрация не нужна. Облачная синхронизация пока не реализована.

## Сейчас в разработке

Основной сценарий — создание привычек, ежедневные отметки и оценка настроения — уже работает. Карточки привычек, редактирование, удаление и напоминания ещё не готовы.

В профиле подготовлено меню для всех привычек, дневника настроения, выбора темы и языка. Эти пункты пока без действий. Функциональность разовых и регулярных дел разрабатывается отдельно и отключена в текущей версии.
