# Habits

Kotlin Multiplatform-приложение для ведения привычек и оценки настроения.

## Локальные фича-флаги

Локальные compile-time флаги находятся в модуле `core:featureflags`, в объекте `FeatureFlags`.

В первой версии дела отключены:

```kotlin
public const val TODOS_ENABLED: Boolean = false
```

При выключенном флаге дела не загружаются и не отображаются, вкладка их создания скрыта, а переход к карточке дела заблокирован. Существующие записи дел в локальной базе не удаляются. Чтобы вернуть функциональность, достаточно установить `TODOS_ENABLED` в `true` и пересобрать приложение.

Подробное описание текущего поведения приложения находится в [BUSINESS_LOGIC.md](BUSINESS_LOGIC.md).
